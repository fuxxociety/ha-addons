# fuxxociety Home Assistant add-ons

[![Add repository to Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Ffuxxociety%2Fha-addons)

To add this repository manually, go to **Settings → Add-ons → Add-on Store**, then **⋮ → Repositories**, and add
`https://github.com/fuxxociety/ha-addons`.

| Add-on | |
|---|---|
| [ESPHome NetWatch](esphome_netwatch/) | Watches every device on the IoT subnet and ranks them by connectivity trouble over time: ping, ARP, mDNS, HTTP, and the ESPHome native API. It separates drops caused by reboots (power or crash) from Wi-Fi drops. |
